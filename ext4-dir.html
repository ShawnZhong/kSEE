kSEE · Files on a disk (ext4)

A directory on a disk

The same mkdir as in memory, but on ext4, where a directory is a file of names in disk blocks.

1. ext4_mkdir makes the directory in one journal transaction. On a disk a directory is a file of names, so ext4_init_new_dir writes its first block with its own two entries, "." (itself) and ".." (its parent), and ext4_add_entry puts the name "sub" into a block of /mnt, the parent.

2. Listing /mnt: ext4_readdir reads the directory's blocks and hands out one entry after another.

Try: list the new directory instead: only "." and "..". Or make a file in it first, then list it.

The program

  1. char buf[256]
  2. mkdirat(AT_FDCWD, "/mnt/sub", 0755)
  3. int fd = openat(AT_FDCWD, "/mnt", O_RDONLY | O_DIRECTORY)
  4. getdents64(fd, buf, 256)
